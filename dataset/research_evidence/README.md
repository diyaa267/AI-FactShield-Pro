# Nadiad verified-claim benchmark

This benchmark is an **evaluation set, not a training set**. Labels are assigned from the cited source, with the URL and evidence excerpt stored for reproducibility.

- 8 real claims are from Nadiad reporting dated 2025–2026.
- 4 false Nadiad-attribution claims are historical fact-check cases because recent Nadiad-specific fact-check coverage is sparse in the indexed sources.
- Do not describe this 12-item benchmark as a representative production dataset. It is a small, manually curated pilot benchmark for the final-semester system.
- The benchmark deliberately keeps evaluation records separate from model training data to reduce leakage.
